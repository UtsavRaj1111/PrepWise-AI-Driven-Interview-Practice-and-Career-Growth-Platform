## 🧠 Overview

**PrepWise** is a full-stack AI-powered platform designed to help students and professionals excel in their career journey.

It combines **AI interview simulation, resume intelligence, and structured aptitude practice** into one unified system — delivering a real-world preparation experience.

---

## ✨ Core Features

### 🤖 AI Interview Simulator
- Real-time technical interview sessions  
- Adaptive difficulty levels (Easy / Medium / Hard)  
- AI-generated feedback and scoring  
- Simulates real interview scenarios  

---

### 📄 Resume Analysis (ATS Engine)
- ATS score evaluation  
- Missing keyword detection  
- Job description matching  
- Actionable improvement suggestions  

---

### 🧠 Aptitude Arena

A structured learning and testing system for placement and interview preparation.
